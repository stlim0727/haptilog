# M3 Concept 04: Advanced Controls & Consent

Follow-up to Concept 03. High-fidelity visual concept board showing the remaining Wear OS UX features: Pause/Resume recording, Audio playback with seek and progress bar, Card-based modular cloud consent, and Live web connection code timer.

## Screens Overview

1. **01 녹음 중 (일시정지 지원)**:
   - 상단 곡면 시계 (10:09)
   - 코럴 녹음 점과 '녹음 중' 라벨
   - 대형 디지털 타이머 (`00:24`)
   - 하단 좌/우 2열 분할 칩: `[⏸ 일시정지]` (다크 뉴트럴 컨테이너) / `[■ 중지]` (코럴 강조)

2. **02 녹음 일시정지**:
   - 앰버 배지 (`⏸ 일시정지됨`)
   - 타이머 일시정지 (`00:24`)
   - 전폭 코럴 주 액션 버튼 (`▶ 이어서 녹음`)
   - 보조 완료 버튼 (`■ 녹음 완료`)

3. **03 오디오 상세 재생**:
   - 지출 카테고리 칩 (`지출 · 12,000원`, 피치 액센트)
   - 3버튼 미디어 컨트롤러: `[⏪ -5s]`, 중앙 대형 원형 일시정지 `[⏸]`, `[⏩ +5s]`
   - 수평 스크러버 트랙과 썸 인디케이터 (`00:14 / 00:38`)
   - 고정폭 타임스탬프

4. **04 클라우드 AI 동의 (카드형 모듈화)**:
   - 타이틀: '클라우드 AI 동의'
   - 3개 톤다운 모듈형 아코디언 카드:
     - `🎙️ 음성 데이터 전송 ▾`
     - `🤖 Google Gemini 분석 ▾`
     - `📍 위치 정보 제외 ▾`
   - 하단 코럴 버튼 `동의하고 시작`, 텍스트 `워치에만 저장`

5. **05 동의 상세 보기 (카드 펼침)**:
   - '클라우드 동의' 상세 안내문 카드 펼침 뷰
   - 우측 미세 스크롤바 인디케이터
   - 하단 2열 액션: `[취소]` / `[동의]`

6. **06 웹 브라우저 연결 (타이머)**:
   - '웹 브라우저 연결' (`haptilog.web.app`)
   - 코럴 테두리 박스 안의 6자리 큰 연결 코드: `7 4 2 9 0 1`
   - 앰버 실시간 카운트다운 배지: `⏱ 04:32 남음`
   - 하단 버튼: `새 코드 만들기`
