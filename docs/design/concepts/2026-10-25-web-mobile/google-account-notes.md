# Google 로그인·계정 복구 흐름 추가 시안

2026-10-25 · [요구사항: Discussion #46](https://github.com/stlim0727/haptilog/discussions/46#discussioncomment-19180660)

[계정 흐름 한눈에 보기](google-overview.png) · [조작 가능한 프로토타입](prototype.html?view=welcome)

이번 변경은 기존 모바일 UX 검토 2회 이후 추가된 인증 요구사항을 **시안에 반영**한 것이다. Google OAuth·운영 설정·데이터 연결 구현 완료를 의미하지 않는다. 실제 인증 작업과 구분해 화면·상태·사용자 안내를 정의한다.

## 상태와 진입 경로

| 사용자 상태 | 화면과 다음 행동 | 표시 원칙 |
| --- | --- | --- |
| 미로그인 | Google로 로그인 / 워치 코드로 연결 | 코드만으로도 시작 가능 |
| 코드로 연결한 기존 사용자 | 목록의 ‘Google 계정에 연결해 기록 보관’ | ‘계정 미연결’을 표시 |
| Google 로그인 완료, 워치 미연결 | 예시 계정과 코드로 확인한 워치를 함께 보여주고 ‘이 계정에 기록 연결’ 확인 | 로그인만으로 연결 완료·복구 가능 표시 금지 |
| 계정 연결 완료 | 내 계정, 계정 연결 완료 상태, 연결된 워치 목록 | 이 계정에 연결한 워치의 업로드 기록만 다시 열람 |
| 기존 워치가 있는 계정 | 현재·이전 워치를 선택해 해당 워치 기록 열람 | 목록·지도·달력의 기록 범위가 선택한 워치와 일치 |
| 새 워치 연결 | 로그인 계정을 표시하고 6자리 워치 코드로 소유 확인 | 새 워치에는 다른 워치 기록을 자동 표시하지 않음 |
| 브라우저 로그아웃 | 계정 연결 유지 안내 후 로그인 진입 화면 | 워치의 영구 계정 연결 해제와 분리 |
| 계정에서 워치 연결 해제 | 대상 워치와 계정 접근 해제 영향을 확인하는 별도 화면 | 로그아웃 버튼과 별도 행동·확인 단계 |
| Google 로그인 실패·취소 | 재시도 또는 워치 코드 연결 | 계정 연결 성공으로 표시하지 않음 |

## 기록 복구 안내

각 계정·연결 화면의 ‘어떤 기록을 다시 볼 수 있나요?’에서 확인한다.

- 계정에 연결한 워치의 **업로드된 기록**을 다시 확인할 수 있다.
- **계정 연결 전에 워치 인증 정보와 기존 브라우저 접근을 모두 잃은 기록은 복구할 수 없다.**
- **워치 로컬에만 남은 미업로드 음성은 Google 로그인으로 복원되지 않는다.**

계정 연결 완료 전 ‘안전하게 복구 가능’ 등 보장 문구를 사용하지 않는다. 계정에서 워치 연결을 해제하는 동작과 원본 음성/기록을 영구 삭제하는 동작을 하나로 합치지 않는다. 기록 보존·재연결 권한의 최종 계약은 인증 구현에서 검증해야 하며, 이 시안은 미확정 삭제 정책을 약속하지 않는다.

프로토타입은 **prototype.html과 account-prototype.js를 같은 폴더에 두고** 브라우저에서 연다. 기본은 코드로 연결한 기존 사용자 상태다. HTML의 링크 또는 아래 URL 파라미터로 상태를 바로 확인할 수 있다.

- `?view=welcome`: 미로그인 진입
- `?view=list`: 코드 연결 사용자·계정 미연결
- `?view=link-account&account=google`: Google 로그인됨·기록 연결 확인 전
- `?view=watches&account=linked`: 예시 계정과 두 워치
- `?view=account&account=linked`: 계정 연결 완료 상태
- `?view=unlink-watch&account=linked`: 별도 연결 해제 확인
- `?view=signin-error`: Google 로그인 실패/취소 안내

Google 버튼과 6자리 코드 입력은 예시 상태만 전환한다. 로그인 버튼은 연결된 워치가 있는 예시 계정을, 기존 사용자의 계정 연결 버튼은 별도 연결 확인 과정을 보여준다. 실제 Google 인증 창·자격 증명 입력·네트워크 요청·음성 접근을 실행하지 않는다. 예시 계정은 minsu@example.com이다.

## 검증

- 320·360·390·430px × 8개 상태 = **32개 화면의 문서 가로 넘침 없음**.
- 코드만 연결하면 계정 미연결로 유지.
- Google 로그인 후에도 명시적 기록 연결 확인 전 완료로 표시하지 않음.
- 이전 워치 선택 시 현재 워치 기록과 섞이지 않음.
- 브라우저 로그아웃 후 다시 로그인해도 워치 계정 연결 유지.
- 별도 계정 연결 해제 후 해당 워치는 계정 목록에서 제외.
- 새 워치 코드 확인 후 다른 워치 기록을 물려받지 않고 빈 상태 표시.
- JavaScript 오류 없음. 수치는 [검사 기록](google/validation.json)에 보존.

실제 OAuth 실패·토큰 만료·소유 검증·계정 병합·이전 기록 접근 권한은 실제 인증 구현에서 검증할 대상이다. 기존 round1/round2 문서와 final/validation.json은 계정 확장 전 검토 기록이며 새 계정 흐름을 두 차례 추가 검토했다는 의미가 아니다.
