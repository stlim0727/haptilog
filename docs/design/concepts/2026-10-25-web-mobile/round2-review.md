# UX 디자이너 2차 검토

판정: 수정 방향은 적절하며, 아래 네 항목을 반영하면 최종 검토용 시안으로 제시할 수 있다. 제품 구현 승인을 뜻하지 않는다.

검토 근거: prototype.html, round1의 list/detail/calendar/empty/map/pair/list-320/calendar-320.png, validation.json. 한국어 정적 예시 데이터를 사용하는 HTML 프로토타입이다. 실제 연결·재생·수정, 실지도, 모바일 실기기, 영어, 200% 텍스트는 이 자료로 검증되지 않았다.

## 개선 확인

- 목록이 첫 화면의 주요 콘텐츠가 됐다. 자동 측정 첫 카드 top은 폭별 약 421–427 CSS px이며 844px 높이 캡처에서 여러 기록을 볼 수 있다.
- 기록 상세가 독립 화면으로 분리되어 제목·원음·음성 텍스트의 관계가 명확하다.
- 빈 날짜 캡처에는 다른 날짜의 상세가 없다.
- 지도 자체가 지도 보기 진입 직후 보이고 실제 지도와의 차이를 화면에 명시했다.
- 연결 화면은 코드 입력과 버튼을 첫 화면에 제공하며 기존 큰 제목의 과도한 분절이 줄었다.
- 보고된 320/360/390/430px 문서 너비는 viewport와 같다. 320px 달력 셀 너비 약40.9px·높이47px은 이 폭에서 7열을 유지하기 위한 현실적 절충이다. 이를 모든 셀이 44×44px라고 보고해서는 안 된다.

## 최종 전 수정 요청

### 1. P2 · 필터 결과에 맞는 지도 기본 장소와 정확한 수량

관찰: map.png는 서울숲 2개, 뚝섬한강공원 1개를 표시하지만 제목에는 ‘3개 위치’라고 쓰여 있다. 코드 map()은 언제나 서울숲 기록을 기본 결과로 만든다. 여행 필터에서는 뚝섬한강공원 기록만 남아도 서울숲 0개 결과가 표시된다.

수정: ‘위치 있는 기록 3개 · 장소 2곳’처럼 단위를 구분한다. 명시 선택 장소가 현재 필터 결과에도 남아 있으면 유지하고, 초기 진입 또는 기존 장소가 빠졌을 때 첫 유효 장소를 선택한다. 위치 있는 기록이 0개면 선택 장소를 해제하고 ‘위치가 있는 기록이 없어요’와 ‘목록 보기’를 제공한다.

합격 기준: 전체/메모/여행/운동 필터에서 마커 수, 선택 장소, 아래 기록이 일치한다. 여행 선택 시 뚝섬한강공원 기록이 바로 표시되고 운동 선택 시 빈 지도의 이유와 목록 이동 수단이 보인다.

### 2. P2 · 화면 전환 후 키보드 포커스 유지

코드 확인: switchView(), periodDialog()의 적용 및 메뉴의 휴지통 이동은 app.innerHTML을 재생성한다. 선택한 컨트롤이 사라진 뒤 새 포커스를 지정하지 않는 경로가 있다. 상세 뒤로가기와 날짜 선택에는 별도 복원 처리가 있으나 모든 경로에 적용되지는 않는다.

수정: 보기 전환은 새 활성 보기 버튼에, 기간 선택은 새 기간 버튼에, 휴지통 진입은 화면 제목에 포커스를 둔다. 닫기/Escape는 원래 호출 버튼에 돌아가야 한다. 재렌더링 후에도 초점이 문서 body로 떨어지지 않게 한다.

합격 기준: Tab/Enter로 보기 변경, 기간 변경, 휴지통 진입·뒤로가기를 연속 수행할 수 있고 매 단계 포커스 위치가 시각적으로 보인다. 모달 열림·닫힘도 같은 방식으로 확인한다.

### 3. P3 · 새로고침 아이콘의 의미

관찰: 목록의 기간 우측 체크 아이콘은 aria-label이 ‘기록 새로고침’이다. 체크는 이 화면에서 완료 상태처럼 읽힐 여지가 있어 동작과 모양이 맞지 않는다.

수정: 순환 화살표로 바꾸고 접근성 이름을 유지한다. 동작이 없는 시안임을 알리는 현재 데모 안내는 유지한다.

합격 기준: 완료·연결 상태와 새로고침 조작을 색이나 맥락 추측 없이 구별할 수 있다.

### 4. P3 · 상세 제목의 한글 단어 분절

관찰: detail.png 제목에서 ‘라떼’가 ‘라 / 떼’로 나뉜다. 가독성 문제이며 지금의 위계나 제목 크기를 다시 축소할 이유는 아니다.

수정: 제목과 기록 카드 제목에 word-break: keep-all을 적용하고 overflow-wrap: anywhere 등으로 긴 URL·공백 없는 문자열만 예외 처리한다. 연결 제목의 의도된 두 줄은 유지한다.

합격 기준: 320/390px에서 일반 한국어 단어가 중간 분절되지 않고 긴 공백 없는 토큰도 가로 넘침을 만들지 않는다.

## 검증 범위와 다음 확인

- validation.json의 back.before=0, y=0과 카드 포커스·메모 필터 복원은 확인할 수 있지만, 이 값으로 실제 스크롤 위치 복원을 입증할 수는 없다. 스크롤이 필요한 기록을 열어 before>0인 상태로 뒤로가기 후 동일 위치를 별도 확인한다.
- 200% 텍스트와 영어는 미검증이다. 현재 결과를 양 언어·확대 접근성 검증 완료로 표현하지 않는다.
- 연결·편집·삭제의 실제 성공/실패와 복원 계약은 제품 구현 단계 검증 대상이다. 시안의 토스트를 구현 완료나 안전성의 근거로 사용하지 않는다.
- 대화형 시안 안의 실제 동작과 설명용 버튼을 명확히 구분해 제시한다.
