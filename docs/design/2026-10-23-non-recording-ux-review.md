# 녹음 외 화면 UX 가시적 검토

기준 소스: main `a01bc196c08becbf30c8939814e43dde2bbaa1e5`. UX 디렉터와 논의한 녹음 목록·상세·설정 진입 전후·웹 연결·클라우드 동의 6개 화면의 검토다. 앱 코드는 바꾸지 않았다.

- [목록과 상세](visuals/non-recording-review/01-recordings.png)
- [설정 진입 전·후](visuals/non-recording-review/02-settings.png)
- [웹 연결과 클라우드 동의](visuals/non-recording-review/03-connection-consent.png)
- [한 문서에서 탐색](visuals/non-recording-review/review.html)

왼쪽은 현재 앱의 기본 글꼴·227dp/API 34 원형 에뮬레이터 캡처다. 원본 PNG/XML은 `visuals/non-recording-review/current/`에 있다. 합성 테스트 녹음을 사용했으며, 오른쪽의 한국어 녹음명·내용·시간은 화면 구조 설명용 예시다. 시안은 아직 구현하지 않았고, 192dp 및 확대 글꼴·터치 영역 검증 전이다.

## 우선순위

1. **시계 겹침:** 기본 글꼴의 `recording-list.png`에서도 시계가 스크롤 항목 위에 겹친다. 시간 표시와 스크롤을 연동한다. 화면 끝에 일부 보이는 스크롤 항목은 정상 동작이며 이 겹침 문제와 구분한다.
2. **목록 식별 정보:** 날짜·길이·분류보다 내용을 알아볼 짧은 요약을 먼저 배치한다. AI 파생 요약은 명시하고, 없으면 날짜 기반 녹음명을 사용한다. 사용자 작성 제목 기능이 이미 있는 것처럼 가정하지 않는다.
3. **상세 첫 화면:** 현재 날짜가 화면 중간부터 시작하고 재생은 요약·전사·구조화 정보·지도·동기화 아래에 있다. 짧은 식별 정보 다음에 재생을 배치한다. 전문 및 부가 정보는 펼칠 수 있게 하되 원문 접근성을 유지한다.
4. **설정 진입:** 현재 접근 위치를 유지하면서 중립색 아이콘+라벨로 강조도를 낮춘다. 설정을 무한 목록의 맨 아래로 밀거나 아이콘만으로 숨기지 않는다.
5. **설정 내부:** 연결·동기화, 도움말·신고·개인정보, 앱 정보로 구분한다. 버전·빌드·업데이트는 앱 정보에서 본다.
6. **웹 연결:** 목적, 주소, 코드 생성 동작을 앞쪽으로 모은다. 이번 검토에서 실제 코드 발급이나 브라우저 연결은 수행하지 않았다.
7. **클라우드 동의:** 데이터와 수신처, 철회 시 효과, 보관·삭제 범위를 나눠 읽기 쉽게 한다. 시안은 첫 구간만 보여 준다. 기존/새 녹음 업로드, 위치 보관, Gemini에 보내는 음성·시각, 위치/ID 메타데이터 제외, 민감정보 경고, AI 오류 가능성, 철회·삭제 한계, 18세 선언, 정책 링크 및 명시적 동의/거절을 생략하지 않는다. 검토 중 동의를 수락하지 않았고 업로드하지 않았다.

## 탐색과 삭제

- 현재 상세→목록은 목록을 다시 구성하고, 설정 복귀 시 ON_RESUME에서 0번으로 이동한다. 시안에서는 기록 탐색 복귀 위치 보존과 명시적 녹음 홈 접근을 구분한다. 기존의 빠른 녹음 접근 의도도 보존해야 한다.
- 재생은 긴 본문을 읽기 전에 접근할 수 있어야 한다. 재생/정지 상태와 실패 안내가 분명해야 한다.
- 삭제는 “워치에서 삭제”로 범위를 명시하고 확인한다. 클라우드 사본 삭제나 구현하지 않은 Undo를 약속하지 않는다. 로컬 삭제 실패 시 상세를 유지하고 결과를 알린다.
- 시안의 짧은 문구와 낮은 강조도는 작은 글꼴·터치 영역 축소로 구현하지 않는다. 기존 스크롤바, 회전 입력, 로컬 우선 저장 및 햅틱 계약을 유지한다.

검토는 에뮬레이터와 소스에 기반하며 실제 Galaxy Watch 사용성 실험을 대신하지 않는다.
