## 실제 구현

700px 이하에서는 기록 우선 목록과 독립 상세 화면을 제공한다. 목록·지도·달력으로 탐색하며 필터와 휴지통을 분리했다. CSV·Notion·연결 해제는 더보기에서 제공한다. 데스크톱의 타임라인·지도와 기존 원음 재생·수정·복원 기능은 유지한다.

상세 진입은 recording URL과 브라우저 History를 사용한다. 뒤로가면 원래 보기·날짜·검색·분류·페이지 스크롤·카드 포커스를 복원한다. 조회 화면을 보존해 달력 선택과 지도 탐색 상태가 상세를 열었다 돌아와도 유지된다. 미저장 텍스트/지출 수정에는 이탈 확인을 제공하고, 상세·편집 화면을 회전할 때 편집기가 다른 레이아웃으로 교체되지 않도록 한다.

달력 날짜·기록은 키보드로 조작 가능한 버튼이다. 빈 날짜에는 다른 날짜 상세를 표시하지 않는다. 날짜 이동 시 현재 월에 맞는 선택을 유지한다. 지도에서는 저장된 좌표별로 기록을 모으며 위치 없는 기록은 목록으로 이동할 수 있다. 지도 타일/모듈 실패 안내와 기록 목록은 유지한다.

## 검증 범위

- TypeScript 검사와 Vite 프로덕션 빌드
- 웹 단위 검사 23개 — 통과
- 웹 브라우저 회귀 검사 29개: 모바일 9개, 기존 포털·Notion 20개 — 모두 통과 (1.6분)
- 프로덕션 헤더 아래 지도 타일·개인정보처리방침 검사 2개 — 통과
- 한국어·영어 × 320·360·390·430px × 목록·지도·달력의 가로 넘침 검사
- 페이지 아래쪽 카드 → 상세 → 브라우저 Back/Forward: 비제로 스크롤·검색·필터·카드 포커스 복원
- 날짜 키보드 조작, 빈 날짜 상세 제거, 달력 날짜 선택 복원
- 지도 분류 전환, 위치 없는 기록의 목록 접근
- 미저장 편집 이탈 취소/확인, 회전 중 초안 보존, 저장 후 새로고침
- 휴지통 이동·복원·연결 해제·모바일 Notion 경로
- 320px에서 계산된 글자 크기를 2배로 만드는 확대 스트레스 검사

실기기·모바일 Safari·OS 글자 확대·실제 오디오 디코딩·실제 백엔드 연결은 이번 로컬 UI 회귀 검사의 범위 밖이다. 프로덕션 헤더 검사는 별도 Playwright 설정으로 실행한다. 배포는 수행하지 않는다.
