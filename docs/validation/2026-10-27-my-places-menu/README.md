# 내 장소 메뉴 이동

웹 메인의 장소 설정 버튼을 제거하고 모바일·데스크톱 모두 `더보기 → 내 장소`로 진입한다. 데스크톱의 음성 CSV와 Notion 내보내기도 더보기에 배치한다. 체류에서 장소를 저장·수정하는 경로와 기존 장소 관리 내용은 유지한다.

- 버튼·다이얼로그·영역 이름: 내 장소 / My places
- 메뉴를 닫은 후 장소 다이얼로그를 열며 모달은 하나만 활성화한다.
- 닫기 또는 Escape 후 메인의 더보기 버튼으로 포커스를 돌린다.
- 기존 기록 필터와 목록 상태를 바꾸지 않는다.

390px·1280px의 메인, 메뉴, 장소 화면은 같은 폴더의 PNG 참조. 합성 테스트 데이터로 촬영했다.

검증: `npm run build`; Playwright 메뉴 진입·포커스, 장소 레이아웃(두 테마), 한·영 전환, 장소 편집·접근권한, CSV·Notion 내보내기 및 통합 저널 회귀 검사.

결과: 빌드 통과. 메뉴·Notion·포털·장소 후속·통합 저널 58개 E2E 통과. 별도 실행에서 장소 레이아웃 4개, 한·영 4개, 공통 동기화 1개도 통과했다. 테스트 경로 변경 중 발견한 숨겨진 메뉴 클릭을 수정한 뒤 해당 장소 후속 테스트도 재검증했다.
